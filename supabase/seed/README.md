## Seed Strategy

- Seed files populate local development databases with realistic curriculum topics, problem specifications, and test cases.
- **Phase 0 Rule:** No fake production metrics, fake reviews, or fake user statistics are allowed.
- Future seeds will be placed in `supabase/seed/seed.sql` and run via `supabase db reset`.
